# Web Motion Fundamentals

Repositorio de seguimiento del curso de Laracasts sobre animación web moderna.

## Contenido del curso

- Transiciones CSS fluidas y accesibles
- Keyframes y animaciones avanzadas
- Scroll-driven animations
- Técnicas SVG
- Web Animations API
- Bibliotecas: Motion.dev, AnimeJS, GSAP

## Estructura

Cada sección del curso tendrá su propia carpeta con los ejercicios y ejemplos.
